# Community code of conduct

## Our commitment

Me Home AI welcomes participants of every background and experience level.
Everyone should be able to participate without harassment or discrimination,
regardless of age, disability, appearance, ethnicity, nationality, race, religion,
sex, sexual orientation, gender identity, or socioeconomic background.

## Expected behavior

Be considerate, use welcoming language, respect differing views, give actionable
feedback, and accept responsibility for mistakes. Critique ideas and code rather
than people. Respect privacy and personal boundaries.

Harassment, threats, sexualized conduct, discriminatory attacks, doxxing,
publishing private information, and sustained disruption are unacceptable.
This policy applies in project repositories, issues, pull requests, discussions,
and other spaces where someone represents the project.

## Reporting and enforcement

The initial community maintainer is @Khagendra01. For a sensitive report, use
the contact options on https://kgenkri.com (linked from the maintainer's GitHub
profile). If a suitable private channel is unavailable, request one in the
community repository without publishing sensitive details.

Maintainers will handle reports discreetly, consider context, avoid retaliation,
and may remove content, warn a participant, or temporarily or permanently restrict
participation. A maintainer involved in a complaint should recuse themself where
another maintainer is available. The project currently has one maintainer and no
independent appeals body; that limitation should be addressed as the team grows.
