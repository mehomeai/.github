# Support

Ask usage and design questions in [community discussions](https://github.com/mehomeai/.github/discussions).
Report reproducible bugs in the affected repository with its bug report form.
For feature requests, explain the user problem and alternatives considered.
There is no guaranteed support response time while the projects are at bootstrap.
Use SECURITY.md for private vulnerability reporting and CODE_OF_CONDUCT.md for
community concerns. Do not post personal or household data in public threads.
