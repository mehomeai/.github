# Security policy

## Supported versions

The projects are in initial development and have no supported stable releases.
Security fixes currently target the default branch. Each project should publish
a support matrix when it starts releasing versions.

## Report a vulnerability privately

In the affected repository, open **Security → Report a vulnerability** to create
a private vulnerability report for the maintainers. The direct URL is
`https://github.com/mehomeai/REPOSITORY/security/advisories/new`, replacing
`REPOSITORY` with the affected project name.

Include affected commits or versions, impact, reproduction steps, and a minimal
proof of concept using synthetic data. Never include real household data,
children's information, credentials, or a live exploit against someone else's system.
Do not use public issues or discussions for undisclosed vulnerabilities.

If private reporting is unavailable, open a public issue containing only a request
to enable a private reporting channel; do not include vulnerability details.

Maintainers will assess the report, coordinate a fix, and discuss disclosure with
the reporter. There is no guaranteed response time or paid bug bounty at this stage.
For ordinary bugs without a security impact, use the bug report issue form.
