# Me — Your intelligence. Yours.

We're building a privacy-first home agentic system: personal AI infrastructure
with a focus on local control, transparent software, and household choice.

[Explore the vision](https://mehomeai.replit.app/me/) · [Join the discussion](https://github.com/mehomeai/.github/discussions)

## Repositories

| Repository | Focus |
| --- | --- |
| [setup-infra](https://github.com/mehomeai/setup-infra) | Local installation and infrastructure bootstrap for Me Home AI. |
| [infra-server](https://github.com/mehomeai/infra-server) | Infrastructure services for the Me Home AI platform. |
| [agentic-framework](https://github.com/mehomeai/agentic-framework) | Agent orchestration framework for privacy-first home AI. |
| [backend-server](https://github.com/mehomeai/backend-server) | Backend services and APIs for Me Home AI. |
| [phone-app](https://github.com/mehomeai/phone-app) | Mobile companion application for Me Home AI. |
| [web-app](https://github.com/mehomeai/web-app) | Web application for Me Home AI. |
| [feed-algorithm](https://github.com/mehomeai/feed-algorithm) | Feed ranking and recommendation components for Me Home AI. |
